❓ ¿Qué significa OSC?

OSC significa Open Source CodePen.

📋 Requisitos Mínimos del Sistema
  • CPU: 1 núcleo @ 500MHz o superior.
  • RAM: 64 MB libre (256 MB recomendados para fluidez absoluta).
  • Disco: 5 MB de espacio disponible.
  • Sistemas: Windows XP/7/10/11, Linux liviano o VMs de VirtualBox.
🔍 ¿Cómo puedo saber mis MB de RAM?

En Windows presiona Ctrl + Shift + Esc para abrir el Administrador de Tareas y ver la pestaña Rendimiento, o abre Mem Reduct para monitorear los megabytes exactos en la barra de tareas.

🌐 ¿Qué sitios se pueden acceder?

Está optimizado para archivos locales (.html, .ez), visores de componentes, proyectos de CodePen estáticos y páginas ultraligeras en HTML puro.

🚫 ¿Por qué no se puede acceder a Google ni a YouTube?

Porque requieren cientos de MB en scripts, telemetría y reproductores pesados que congelarían computadoras de gama modesta. OSC Browser elimina ese bloatware para garantizar la máxima velocidad local.

🦆 ¿Se puede probar en DuckDuckGo?

Sí, mediante la interfaz ligera DuckDuckGo Lite (html.duckduckgo.com), diseñada para navegadores de bajo consumo sin JavaScript complejo.

🐧 ¿Funciona en Linux?

Sí. Funciona nativamente o sobre capas livianas en distribuciones retro/ligeras como Lubuntu, Puppy Linux o Alpine.

🎯 ¿Para quién está pensado?

Para creadores de interfaces web minimalistas, animadores 2D, usuarios de máquinas virtuales con poca RAM asignada y desarrolladores cansados del consumo excesivo de memoria en navegadores modernos.

📦 ¿Está en GitHub?

Sí, el repositorio vive en GitHub en la rama main para descargar el proyecto en .zip en un solo clic.

💡 ¿En dónde nació OSC Browser?

Nació para erradicar las colgaduras de sistema, pantallas azules al 1% y errores vacíos como "The text could not be generated" en equipos de recursos limitados.

⚙️ ¿Qué es OSC Engine?

El núcleo interno de renderizado ligero encargado de procesar HTML, CSS y JavaScript local consumiendo el mínimo de procesador.

📜 ¿Es compatible con formatos personalizados o código local?

Soporta componentes SVG, librerías personalizadas y scripts en lenguajes propios como EZScript (.ez).

💻 ¿Qué hago si me sale una Pantalla Azul (BSOD)?

Aplica limpieza de memoria RAM con Mem Reduct, apaga VMs secundarias en VirtualBox y reinicia la instancia del navegador.

🔋 ¿Consume mucha batería en laptops antiguas?

No. Al no ejecutar rastreadores ni minería de datos en segundo plano, el uso de CPU se mantiene cercano al 0%, alargando la vida de baterías viejas o desgastadas.

🌙 ¿Tiene modo oscuro integrado?

Sí, el tema estándar usa paleta de alto contraste basada en gris oscuro (#0d1117) para reducir el cansancio visual y el consumo en pantallas OLED/LCD.

⚛️ ¿Requiere bibliotecas pesadas como React, Vue o Angular?

Para nada. Todo funciona con Vanilla JS, HTML5 estándar y CSS3 nativo. Cero dependencias externas en la carpeta node_modules.

📄 ¿Cómo abro un archivo .ez de EZScript?

Solo arrastra el archivo con extensión .ez a la ventana de OSC Browser o selecciónalo desde la opción de carga local. OSC Engine lo interpretará al instante.

🛡️ ¿Soporta extensiones como AdBlock o uBlock Origin?

No son necesarias. Al no permitir la carga automática de dominios de publicidad externa ni banners pesados, el bloqueo viene integrado a nivel de arquitectura.

📑 ¿Qué pasa si intento abrir 50 pestañas a la vez?

Cada pestaña consume menos de 2 MB de memoria, pero se recomienda moderación en PCs con menos de 128 MB de RAM para evitar usar memoria de intercambio en disco (swapping).

🕵️‍♂️ ¿Guarda historial de navegación o cookies rastreadoras?

No guarda rastreo de navegación global. Los datos se almacenan de manera local únicamente si el componente utiliza la API de localStorage del sistema.

🔒 ¿Mis datos o archivos locales corren algún riesgo?

Es 100% seguro. Al ser un entorno aislado (*sandbox*) y local-first, ningún script tiene permisos para enviar tu información a servidores remotos.

🎮 ¿Es compatible con gráficos 3D o WebGL?

Soporta Canvas 2D y SVG acelerado por software. No incluye WebGL pesado para no forzar tarjetas gráficas integradas antiguas o controladores obsoletos.

⚖️ ¿Por qué el proyecto pesa menos de 1 MB?

Porque elimina el motor Chromium entero y aprovecha las APIs nativas del sistema operativo. Sin ejecutables inflados ni redundancia de archivos.

🎨 ¿Puedo personalizar los colores y temas de la interfaz?

Sí, modificando directamente las variables CSS en la regla :root del archivo principal (--bg, --accent, etc.).

📶 ¿Requiere conexión a Internet para funcionar?

No. Funciona de manera totalmente **Offline**. Es ideal para trabajar en lugares sin señal o en computadoras desconectadas de la red.

🚨 ¿Qué hace OSC Browser cuando la RAM se agota por completo?

Detiene las animaciones secundarias y pausa la ejecución de temporizadores en bucle para prevenir la congelación del sistema operativo.

🧹 ¿Cómo limpio la memoria mientras uso la aplicación?

Puedes presionar el botón de refresco local o ejecutar herramientas externas como Mem Reduct con la combinación de teclas configurada.

📱 ¿Funciona en teléfonos móviles o tablets antiguas?

Es adaptable gracias a su diseño responsivo CSS. Corre dentro de cualquier WebView nativo de sistemas Android clásicos o navegadores móviles ligeros.

🔊 ¿Soporta reproducción de audio y efectos de sonido?

Sí. Soporta etiquetas de audio nativas HTML5 (<audio>) y la Web Audio API para reproducir efectos de sonido o tonos sintetizados en código.

🤖 ¿Por qué no incluye asistentes de voz ni chats de IA integrados?

Porque la IA integrada genera consumo constante de red, memoria y procesador. Priorizamos el rendimiento puro sobre características infladas.

💾 ¿Cómo se instala sin usar un asistente .exe pesado?

No requiere instalación con registro. Únicamente descarga el archivo .zip desde la rama main en GitHub, descomprime la carpeta y abre el archivo principal.

🖥️ ¿Es compatible con sistemas retro como Windows XP o 7?

Totalmente. No utiliza llamadas a librerías de sistemas modernos que causen errores del tipo "DLL no encontrada" en versiones clásicas de Windows.

📦 ¿Qué rendimiento tiene dentro de VirtualBox?

Excelente. Una máquina virtual con Windows 10/7 asignando únicamente 256 MB de RAM o incluso 128 MB puede ejecutarlo a 60 FPS sin ralentizar la PC anfitriona.

💡 ¿Puedo correr el componente "Light Switch" aquí?

Sí, fue diseñado originalmente para probar la física de interruptores, ciclos día/noche y efectos parallax SVG sin tirones de cuadros por segundo.

✏️ ¿Cómo puedo cargar un proyecto exportado de CodePen?

Copia el bloque HTML, CSS y JS unificados dentro de un único archivo index.html y ábrelo directamente con OSC Browser.

🔄 ¿Tiene actualizaciones automáticas que reinicien mi trabajo?

Jamás. Tú tienes el control total sobre cuándo actualizar el código fuente bajando una nueva versión del repositorio.

🎞️ ¿Se pueden visualizar animaciones hechas en FlipAnim?

Sí. Puedes importar los fotogramas exportados como GIFs ligeros o reconstruir la secuencia de imágenes con un script simple en JavaScript.

🕹️ ¿Se pueden ejecutar juegos 2D o retro?

Juegos basados en lógica Canvas 2D ligera (tipo Pong, Snake, Tetris o plataformas de trazo simple) corren de manera óptima sin sobrecargar la memoria.

🔓 ¿El código del proyecto es Open Source?

Sí, es totalmente libre y abierto para que cualquier usuario pueda inspeccionar, modificar o adaptar el código según sus necesidades de hardware.

⚠️ ¿Qué pasa si mi script entra en un bucle infinito (while true)?

El motor del entorno aísla la pestaña para que puedas cerrarla sin congelar todo el sistema ni forzar el apagado por botón.

🌿 ¿Por qué se utiliza la rama "main" para las descargas?

Para simplificar el acceso a usuarios de todos los niveles: abres el repositorio, das clic en Code -> Download ZIP y tienes el proyecto listo sin aprender comandos Git.

🕶️ ¿Qué define la estética del proyecto?

La combinación de un diseño minimalista, contraste oscuro tipo terminal, tarjetas con bordes definidos e información clara orientada a la velocidad.

🛠️ ¿Cómo puedo sugerir cambios o enviar mejoras a OSC Engine?

Puedes abrir un Issue o enviar un Pull Request en el repositorio oficial de GitHub proponiendo optimizaciones de código o nuevas funciones ligeras.
